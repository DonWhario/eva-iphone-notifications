# Capturas de pantalla

Coloca aquí las imágenes que muestra el README principal:

| Archivo | Contenido sugerido |
|---|---|
| `menu.png` | El menú del icono de sobre en la barra superior (estado "Conectado a: …", No molestar, Sonido, etc.). |
| `notificacion.png` | Una notificación de mensaje entrante (banner del sistema o ventana propia). |
| `preferencias.png` | El panel de Preferencias de la extensión. |

Cómo capturar en GNOME:

- Región: **Impr Pant** y selecciona el área, o `gnome-screenshot -a`.
- Ventana concreta: `gnome-screenshot -w`.

Guarda los PNG con esos nombres exactos en esta carpeta y haz commit; el README
los mostrará automáticamente.
